# Jônatas Brito Ferreira

**Software Engineer at [Shema — Oral Bible Translation](https://github.com/shemaobt) (YWAM Kansas City)** · final-semester Software Engineering student at UFC Quixadá · Ceará, Brazil

I build the software behind the Oral Bible Translation Lab: tools that help communities translate the Bible into languages that are spoken, not written. Before that I spent almost two years at V360 building fiscal and tax software integrated with large ERPs.

## Now — Shema OBT

Building the lab's platforms, from the mobile apps used in the field to the backend they share.

| Project | What it is | Stack |
| --- | --- | --- |
| [internalization-room](https://github.com/shemaobt/internalization-room) | Voice-first app for the oral Bible translation flow | Flutter, Dart |
| [shema-api](https://github.com/shemaobt/shema-api) | Shared backend: auth, app-scoped RBAC, PostgreSQL, Cloud Run | Python, FastAPI |
| [oral-collector](https://github.com/shemaobt/oral-collector) | App to record and preserve oral stories with local communities | Flutter, Dart |

Plus internal web tools in React and TypeScript.
